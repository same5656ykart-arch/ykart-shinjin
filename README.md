# 現地調査ナビ（ykart-shinjin）

新人スタッフがリフォームの現地調査で使う、スマホ向けのチェックアプリです。

## 使い方（一本道）

1. **工事の種類を選ぶ**：トイレ・浴室・洗面化粧台・キッチン・建具交換・床張り替え・クロス張り替え・外壁塗装・雨漏れ（複数OK）
2. **調査シートを上から埋める**：種類ごとに「見る → 測る → 写真を撮る → 聞く」が並びます
   - 見る：チェックを付ける。気になる点はひとことメモ
   - 測る：mm で入力（㎜以外は「幅×高さ」の文字でOK）
   - 写真：項目ごとに「撮る」ボタン。撮った物はサムネイルで確認
   - 聞く：質問に対してお客様の言葉をそのままメモ
   - 最後に「どの工事でも」（給湯器・分電盤・搬入経路・駐車）
3. **お客様情報**：名前・住所・電話・担当・築年数
4. **まとめ**：残りの確認、報告文のコピー、「上司に報告する」、「資料をまとめて書き出す（ZIP）」

## 書き出すZIPの中身（見積もりアプリへの取り込み用）

| ファイル | 内容 |
|---|---|
| `現調データ.json` | 項目名が日本語のままの構造データ。`工事[]` ごとに `選択` / `見る` / `採寸` / `計算` / `写真` / `聞く`。`_app` にはこのアプリに戻すための元データ |
| `報告書.txt` | 報告文（上司への報告と同じ文章） |
| `写真/01_トイレ_全体.jpg` … | 撮った写真。JSON の `写真[].ファイル` と対応 |

JSON の `形式` は `ykart-genchi-v1`。見積もりアプリ側はこの JSON と写真フォルダを読めば、現調の内容をそのまま取り込めます。

## 上司に報告する

- スマホ：共有画面が開き、LINE・メールなどに報告文と ZIP を送れます
- PC や共有が使えない時：ホーム画面の「設定」に上司のメールアドレスを入れておくと、そのアドレス宛のメールを作ります。報告文はコピーもされます

## データの取り込み

ホーム画面の「設定・データの取り込み」で、書き出した ZIP（写真つき）か JSON を読み込めます。別の端末や PC で続きを見るときに使います。

データはスマホのブラウザ内に保存されます。サーバーには送りません。

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリ → Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/ykart-shinjin/` で開けます
4. スマホで開いて「ホーム画面に追加」するとアプリのように使えます。一度開けば電波のない現場でも動きます

## トップ画面の背景写真

リポジトリの直下に `hero.jpg` という名前で写真を置くと、トップ画面の背景に自動で表示されます（横長・1600px幅程度・500KB以下が目安）。写真が無い間は、夕景の色味と家並みの線画が表示されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML / CSS / JS をこの1ファイルにまとめています） |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフライン用キャッシュ |
| `icon.svg` | アイコン |
| `hero.jpg` | （任意）トップ画面の背景写真。置くだけで反映 |

## 項目を変えたいとき

`index.html` の `TYPES` に、種類ごとの `see`（見る）/ `measure`（測る）/ `shots`（写真）/ `ask`（聞く）が配列で並んでいます。1行足す・直すだけで画面と報告文に反映されます。

```js
see:[ ['便器のメーカー・型番・年式','タンクのフタ裏か便器の側面にシール'], ... ],
measure:[ ['排水芯：壁から排水管の中心まで','mm','200が今の標準'], ... ],
shots:[ ['型番シール','タンクのフタ裏・便器側面'], ... ],
ask:[ ['一番困っていることは？','掃除・臭い・寒さ・古さ など'], ... ],
```

## 注意

- 写真を大量に撮ると端末の保存容量を使います。調査が終わったら「まとめ」から JSON を書き出して PC に保存し、古いデータは削除してください
- ブラウザの「サイトデータを削除」を行うとデータが消えます
