# 現地調査ナビ（ykart-shinjin）

新人スタッフがリフォームの現地調査で使う、スマホ向けのチェックアプリです。
「基本 → 聞く → 見る → 測る → 写真 → まとめ」の順に進めると、聞き忘れ・見落としを防げます。

## できること

- **新人ガイド**：各画面に「何を見るか」「お客様に何と言うか」の声かけ例つき
- **現場チェック**：外部・水まわり・内装・窓・電気・外構の 27 項目を ○△× で記録。△× には写真とメモ
- **採寸**：部屋（W×D×H、㎡と帖を自動計算）と開口部・設備サイズ
- **写真**：カメラで撮ってその場で分類。端末内に縮小保存
- **まとめ**：未入力チェック、報告文の自動生成（LINE・メールに貼れる）、JSON 書き出し
- **オフライン対応**：一度開けば電波のない現場でも動く（HTTPS で公開した場合）
- データはスマホの中（ブラウザ）に保存されます。サーバーには送りません

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリ → Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/ykart-shinjin/` で開けます
4. スマホで開いて「ホーム画面に追加」するとアプリのように使えます

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML / CSS / JS をこの1ファイルにまとめています） |
| `manifest.json` | ホーム画面に追加するための設定 |
| `sw.js` | オフライン用キャッシュ |
| `icon.svg` | アイコン |

## 項目を増やしたいとき

`index.html` の `AREAS` 配列に項目を足すだけで、チェック画面・写真の分類・報告文に反映されます。

```js
{id:'wall', name:'外壁', look:'ひび割れ・チョーキング…'}
```

## 注意

- 写真を大量に撮ると端末の保存容量を使います。調査が終わったら「まとめ」から JSON を書き出して PC に保存し、古いデータは削除してください
- ブラウザの「サイトデータを削除」を行うとデータが消えます
